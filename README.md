# sensor-code-tutor

一个以真实项目为教材的机器人与传感器代码教学 Skill。给它一个项目目录或 Git 仓库，它会先弄清程序的入口、模块和数据流，再按难度带你阅读代码，逐步串起 C++、工程实现、数学、传感器原理和算法。

它面向想学会**自己读懂项目**的人：每次只处理一个连贯的小范围，先让学习者尝试解释，再围绕真实代码纠正和补充。它不会把一个项目一次性概括成一大篇讲义。

## 适用范围

可用于 LiDAR/雷达、IMU、相机、GNSS、编码器等传感器项目，也适用于驱动、点云和图像处理、目标检测与跟踪、定位建图、里程计、传感器融合及状态估计。代码教学覆盖项目中实际出现的 C++、STL、Eigen、ROS/ROS 2、坐标变换、概率、线性代数和优化知识；**不限定于 SLAM**。

## 它怎样带你学习

1. **建立项目地图：**从文档、构建文件、入口程序、ROS 节点、消息、配置和核心接口中，找出输入、主要模块、调用关系和输出。
2. **制定阅读路线：**依据项目真实代码安排课程，通常从入口和数据结构出发，逐步进入预处理、时间与坐标关系、核心算法及较深的数学。
3. **逐段读代码：**默认选一个约 20～80 行、逻辑连贯的区域；如果只卡在一个 C++ 符号或 Eigen 表达式，就缩小到几行。
4. **先猜再讲：**先展示代码，让学习者用自己的话预测行为；随后按需拆解语法、类型、数据流、公式、传感器意义和算法作用。
5. **回到系统：**每学完几段，就把局部代码放回传感器到输出的完整路径，避免只认识语句却不理解整个程序。

教学时会追踪坐标系方向、时间戳来源、单位、标定、噪声和数据有效性。遇到不熟悉的符号，会先给一个最小例子，再回到项目原句；已经掌握或主动要求跳过的内容不会反复提问。

## 安装

把仓库放进 Codex 的全局 Skills 目录，目录名保持为 `sensor-code-tutor`：

```bash
git clone https://github.com/Hao-y318/sensor-code-tutor.git ~/.codex/skills/sensor-code-tutor
```

如果设置了 `CODEX_HOME`，可把目标目录改为 `$CODEX_HOME/skills/sensor-code-tutor`。安装后可在新会话中显式调用 `$sensor-code-tutor`；Skill 也允许自动发现。

## 使用示例

```text
$sensor-code-tutor 请扫描这个机器人项目，先建立项目地图和适合我的学习路线。暂时不要解释算法细节。
```

```text
$sensor-code-tutor 我正在读 src/imu_processor.cpp。请从一个容易理解的函数开始，先让我猜这段代码在做什么。
```

```text
$sensor-code-tutor 这一行里的 const auto& 我看不懂。请先讲语法，再回到原代码。
```

第一次接触项目时，最好提供项目目录或仓库地址，以及你正在做的任务、已有基础和最困惑的代码。后续可以直接说“继续”“跳过这个”“这句看不懂”，Skill 会沿着当前学习进度调整。

## 教学边界

- 以检查过的源代码为依据；不凭变量名猜测坐标系、单位或算法行为。
- 默认只读；教学请求本身不会授权修改项目代码或替学习者完成机器人任务。
- 数学和高级 C++ 按实际代码逐步引入，不要求一开始就掌握完整的 SLAM、李群或优化理论。
- 用户明确要求直接解释时会直接回答，不强制进行猜题。
